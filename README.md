# Лабораторная работа №2

## Выполненные требования

- Основные стили подключены из внешнего файла `style.css`.
- В `:root` определены переменные цветов и шрифта.
- Внутренний блок `style` задаёт квадратные маркеры списка навыков.
- Единственный inline-стиль демонстрирует `display: flex` у формы.
- Использованы `position: static`, `position: relative` и `position: absolute`.
- Реализованы состояния `:hover`, `:active`, `:focus` и `:visited`.
- Псевдоэлементы `::before` и `::after` создают волны рядом с проектами.
- При наведении волны меняют цвет и получают анимацию `shake`.
- При нажатии кнопка уменьшается до 98%.
- Использована контрастная тёмно-синяя и фиолетовая цветовая гамма.

## Запуск

Откройте файл `index.html` в браузере.

## Проверка

HTML- и CSS-код провалидированы с помощью сервисов W3C.
